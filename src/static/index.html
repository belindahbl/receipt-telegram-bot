🤖 Receipt Scanner Bot

Telegram Bot Administration Panel

📋 Bot Status

This is the administration panel for your Receipt Scanner Telegram Bot. The bot is designed to process receipt images sent via Telegram and automatically save the extracted data to Google Sheets.

🔧 Setup Instructions

Step 1: Create a Telegram Bot

1. Message @BotFather on Telegram 2. Send /newbot 3. Choose a name and username for your bot 4. Copy the bot token

Step 2: Set Environment Variables

TELEGRAM_BOT_TOKEN=your_bot_token_here OPENAI_API_KEY=your_openai_api_key GOOGLE_SHEETS_CREDENTIALS_JSON=your_service_account_json GOOGLE_SHEETS_ID=your_google_sheets_id

Step 3: Set Webhook URL

📱 How to Use

Once your bot is set up:

  1. Find your bot on Telegram and start a conversation
  2. Send /start to see the welcome message
  3. Take a photo of a receipt and send it to the bot
  4. Review the extracted data and confirm to save to Google Sheets

🔍 Features

  • ✅ AI-powered receipt OCR using OpenAI Vision
  • ✅ Automatic data extraction (date, company, amounts)
  • ✅ Interactive confirmation with inline buttons
  • ✅ Direct Google Sheets integration
  • ✅ Singapore GST calculation (9%)
  • ✅ Error handling and user feedback
